# 小白也能懂的 Hermes 入门指南

> 一个开源 AI 智能体，让你在终端、微信、Telegram 上随时拥有一个会「自学成长」的 AI 助手

---

## 一、Hermes 是什么？

简单说：**Hermes 是一个开源的 AI 智能体框架**，由 Nous Research 团队开发。

它跟 Claude Code、OpenAI Codex 属于同一类产品——都是能**自主调用工具、执行任务的 AI 助手**。但 Hermes 有几个独一无二的亮点：

| 特点 | 说明 |
|------|------|
| 🧠 **会自学** | 用过的东西能记住，下次不用重复教 |
| 📱 **全平台** | 终端、微信、Telegram、Discord……同一套大脑 |
| 🔄 **换模型自由** | DeepSeek、Claude、GPT、本地模型随便切 |
| 🛠️ **工具丰富** | 浏览器、终端、文件、代码、图片……全能 |

## 二、快速上手（3 分钟）

### 安装

一行命令搞定：

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

装完直接运行：

```bash
hermes
```

就这么简单，你已经进入了一个 AI 对话界面。

### 选择模型

```bash
hermes model
```

会弹出交互式选择器，支持 20+ 供应商：

- **OpenRouter**（推荐入门，一个 key 用遍所有模型）
- **DeepSeek**（性价比之王）
- **Anthropic Claude**（代码能力强）
- **OpenAI GPT**（生态最全）
- 甚至**本地模型**（llama.cpp 跑 GGUF）

选好后把 API Key 填进 `.env` 文件即可。

### 快速验证

```bash
hermes chat -q "你好，能帮我列出当前目录的文件吗？"
```

如果返回了文件列表，说明安装成功！

## 三、核心概念（理解了就不小白了）

### 3.1 工具集（Toolsets）

Hermes 的能力来自于各种「工具」。就像手机装 App 一样，你可以自由开关：

```bash
hermes tools list
```

常用工具集：

| 工具集 | 用处 |
|--------|------|
| `terminal` | 执行 Shell 命令 |
| `file` | 读写搜索文件 |
| `web` | 联网搜索 |
| `browser` | 操控浏览器（自动填表、截图） |
| `vision` | 分析图片 |
| `memory` | 跨会话记忆 |
| `delegation` | 派生子智能体并行干活 |
| `cronjob` | 定时任务 |

### 3.2 技能（Skills）—— 最酷的功能

这是 Hermes 的**灵魂功能**。

传统 AI 助手每次对话都是「失忆」的。但 Hermes 可以**把学会的东西保存成「技能」**——下次遇到同类任务，它自动加载技能，不用你重新教。

比如：
- 解决了一个复杂的 Git 冲突 → 保存为技能 → 下次自动会处理
- 摸索出了某个 API 的调用方式 → 保存为技能 → 下次直接用
- 发现一个工作流的坑 → 保存到技能 → 下次自动避开

这就好比 AI 在「积累工作经验」，越用越聪明。

### 3.3 记忆（Memory）

跟技能不同，记忆是**关于你个人的信息**：
- 你喜欢什么风格的回答
- 你的项目用什么技术栈
- 你常用的时区、路径、习惯

Hermes 会记在脑子里，每次对话都自动加载。你用久了会发现它越来越「懂你」。

### 3.4 网关（Gateway）—— 跨平台

这是 Hermes 的另一个王牌：**一个 AI，多平台使用**。

```bash
hermes gateway setup
```

配置好后，同一个 Hermes 可以同时：
- 📱 在微信上回复你
- 💬 在 Telegram 上聊天
- 🖥️ 在终端里工作
- 🎮 在 Discord 上协作
- 📧 处理邮件

所有平台共享同一个「大脑」——记忆、技能、会话历史全互通。

## 四、小白常见场景

### 场景 1：写代码

你跟它说「帮我写一个 Python 爬虫，抓取知乎热榜」，它会：
1. 创建文件
2. 写代码
3. 运行测试
4. 修复报错
5. 给你最终版本

### 场景 2：分析数据

你丢给它一个 CSV：「分析一下这个月的销售趋势」，它会：
1. 读取文件
2. 写 Python 脚本分析
3. 生成图表
4. 给你结论

### 场景 3：定时任务

```bash
# 每天早 9 点检查股市行情
hermes cron create "0 9 * * *" \
  --prompt "查询上证指数和深证成指今日行情" \
  --deliver telegram
```

### 场景 4：联网研究

「帮我调研一下最近最火的 AI 开源项目」
→ 它会联网搜索、阅读多篇文章、汇总报告给你。

## 五、常用命令速查

### 日常使用

| 命令 | 作用 |
|------|------|
| `hermes` | 启动交互式对话 |
| `hermes chat -q "问题"` | 单次提问 |
| `hermes -r` | 恢复上次会话（断点续聊） |

### 配置管理

| 命令 | 作用 |
|------|------|
| `hermes setup` | 设置向导 |
| `hermes config` | 查看配置 |
| `hermes config edit` | 编辑配置 |
| `hermes doctor` | 健康检查 |
| `hermes model` | 切换模型 |

### 技能与工具

| 命令 | 作用 |
|------|------|
| `hermes skills list` | 查看已安装技能 |
| `hermes skills browse` | 浏览技能商店 |
| `hermes tools list` | 查看可用工具集 |
| `hermes tools` | 交互式管理工具 |

### 会话控制（对话中输入）

| 命令 | 作用 |
|------|------|
| `/new` | 新对话 |
| `/retry` | 重新回答 |
| `/model 模型名` | 切换模型（不中断） |
| `/skill 技能名` | 加载技能 |
| `/compress` | 压缩上下文 |
| `/help` | 查看所有命令 |

## 六、进阶之路

当你不再满足于基础用法后，可以探索这些高级功能：

### 🧩 插件系统
```bash
hermes plugins list
hermes plugins install <name>
```

### 📡 MCP 服务器
连接 Claude Code、IDE 等外部工具：
```bash
hermes mcp add my-server --command "uvx my-mcp-server"
```

### 👤 多配置档（Profiles）
不同的项目用不同的配置和记忆：
```bash
hermes profile create work
hermes profile create personal
hermes profile use work
```

### 🔗 Webhook 接入
让外部系统触发 Hermes 执行任务：
```bash
hermes webhook subscribe build-notify
```

### 👥 多智能体协作
一个 Hermes 调度多个子智能体并行干活，像一支 AI 团队在为你工作。

## 七、常见问题

**Q: Hermes 免费吗？**
A: 软件本身是开源的（MIT 协议），完全免费。你只需要支付 AI 模型的 API 费用（一个 key 几块钱起步，能用很久）。

**Q: 我可以用微信控制它吗？**
A: 可以。配置网关后，微信上发消息给 Hermes，它会自动回答并执行任务。

**Q: 跟 ChatGPT 网页版有什么区别？**
A: Hermes 能调用你电脑上的工具——读写文件、执行代码、操控浏览器、定时任务。ChatGPT 网页版做不到这些。

**Q: 代码能力跟 Claude Code 比如何？**
A: Hermes 支持换模型，你完全可以给它配上 Claude 模型。同时它比 Claude Code 多了跨平台、技能系统、记忆力等特性。
